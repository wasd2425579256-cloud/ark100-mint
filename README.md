# ARK100

Static pre-mainnet shell for ARK100. Publish path `./`, build command `echo ok`. `index.html` is served at `/`.

Cabin rates are the TicketNFT numbers: Economy 70% at 100 ARK/day, Business 25% at 200, Captain 5% at 600, drawn after mint with `requestCabin` / `settleCabin`. Sunk tickets produce 0. Market, dashboard, and activity rows are labeled demo data. Sale, TicketNFT, ARK, and Pot stay `PENDING_MAINNET`. The top bar switches 中文 / EN (`localStorage` key `ark100-lang`). A `zh` browser language opens in Chinese; every other language opens in English.
